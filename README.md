## Cómo abrirlo

- **Windows:** si sale el aviso azul de SmartScreen, pulsa **Más información** y luego **Ejecutar de todas formas**.
- **Mac:** la primera vez, clic derecho en Taller → **Abrir** → **Abrir**.
- **Linux:** AppImage: `chmod +x Taller-0.6.1-linux-x86_64.AppImage` y ábrelo. O instala el .deb: `sudo apt install ./Taller-0.6.1-linux-amd64.deb`.
